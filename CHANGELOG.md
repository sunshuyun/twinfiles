# Changelog

## 0.1.0 — 2026-10-21

Initial implementation:

- Read-only recursive duplicate discovery using file size and streamed SHA-256.
- Terminal, JSON, and static HTML reports.
- Windows interactive launcher and fictional sample files.
- Exclusions, link handling, cancellation, file-change detection, and scan-error reporting.
- Node.js built-in tests and GitHub Actions test configuration.

This is the initial version. No historical releases or user adoption are implied.
